#  E-Commerce Website

A simple full-stack E-Commerce web application built using *Flask (Python)* and *SQLite*.

##  Features
-  User Registration & Login (Password hashing)
-  Product Listing
-  Add to Cart
-  Address Page
-  Payment Page
-  Order Success Page
-  Secure authentication using Werkzeug
-  SQLite Database integration
##  Tech Stack

- Backend: Python (Flask)
- Frontend: HTML, CSS
- Database: SQLite
- Authentication: Werkzeug Security
